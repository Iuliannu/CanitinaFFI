# CantinaFFI - Lucrarea de laborator nr. 3 (Java)

Standul „Shaorma Express FFI”. Clasele sunt in pachetul `lab3`.

    javac -d out src/lab3/*.java
    java -cp out lab3.Etapa2Demo   # ... Etapa3Demo, Etapa4Demo, Etapa5Demo, Etapa6Demo
    java -cp out lab3.ZiLaStand            # scenariul fix
    java -cp out lab3.ZiLaStand interactiv # comenzi de la tastatura

Parametrii personali (N, minim produse, reducere combo, k) se schimba in `Parametri.java`.
